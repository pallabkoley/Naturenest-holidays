<h2>📖 About Project</h2>

<p>
  NatureNest Holidays is a dynamic travel platform built with Core PHP and MySQL.
  It showcases holiday packages, treks, festival tours, offbeat stays, car rentals, and destination weddings. 
  It includes a customer-facing website and a powerful admin panel to manage bookings, 
  products, enquiries, and website content.
</p>

<h2>✨ Key Features</h2>

<h3>🌐 Frontend</h3>
<ul>
  <li>Tour Packages with detailed itineraries &amp; pricing</li>
  <li>Trekking &amp; Adventure packages</li>
  <li>Festival Tours &amp; Destination Weddings</li>
  <li>Offbeat Stays and Car Rentals</li>
  <li>Dynamic Hero Slider &amp; Customer Testimonials</li>
  <li>Booking Enquiry and Contact forms</li>
</ul>

<h3>🔐 Admin Panel</h3>
<ul>
  <li>Dashboard and Booking Management (Tour &amp; Trek)</li>
  <li>Tour Packages, Destinations, and Festivals</li>
  <li>Offbeat Stays, Rental Cars, and Destination Weddings</li>
  <li>Customer Enquiries, Testimonials, and Reviews</li>
  <li>Hero Slider, Team Members, and Site Settings</li>
  <li>User Management and Reports</li>
</ul>

<h2>⚙️ Installation &amp; Setup</h2>

<ol>
  <li>Clone the repository.</li>
</ol>

<pre><code>git clone https://github.com/pallabkoley/Naturenest-holidays.git</code></pre>

<ol start="2">
  <li>Place the project inside the XAMPP <code>htdocs</code> directory.</li>
  <li>Start Apache and MySQL from the XAMPP Control Panel.</li>
  <li>Create the database and import the provided SQL file.</li>
  <li>Update the database credentials in the configuration file.</li>
  <li>Open the project through localhost in your browser.</li>
</ol>

<h2>🔒 Security</h2>

<ul>
  <li>Validate user inputs and use secure database queries.</li>

</ul>
